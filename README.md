## Обзор проекта

Данный проект представляет собой комплексную базу данных PostgreSQL, разработанную для демонстрации навыков проектирования схем данных, написания сложных SQL-запросов и анализа информации в **четырех независимых предметных областях**:

| № | Подсистема | Описание |
|---|------------|----------|
| 1 | **Транспортные средства** | Автомобили, мотоциклы и велосипеды с характеристиками |
| 2 | **Гоночные автомобили** | Участие машин в гоночных соревнованиях, позиции и классы |
| 3 | **Гостиничные бронирования** | Отели, номера, клиенты и история бронирований |
| 4 | **Управление персоналом** | Иерархическая структура сотрудников, проекты и задачи |

Проект включает:
- ✅ Docker-контейнеризацию PostgreSQL
- ✅ Полные скрипты создания таблиц (`CREATE TABLE`)
- ✅ Тестовые данные (`INSERT` скрипты)
- ✅ Решения аналитических задач (`SELECT` запросы)

## Быстрый старт

### Предварительные требования

- Установленный **Docker** и **Docker Compose**
- Свободный порт `5430` на локальной машине
- Любой SQL-клиент для подключения

### Запуск базы данных

```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd postgres-project

# 2. Запустите контейнер
docker-compose up -d

# 3. Проверьте статус
docker ps | grep postgres_session
